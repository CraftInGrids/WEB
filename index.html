What is CIM?

A common language for exchanging power system information.

⚡ Power Systems

CIM provides a standardized representation of electrical networks, equipment and topology.

🔄 Interoperability

Different software systems can exchange power system data using a common model.

📊 Data Exchange

CIM supports structured information exchange between TSOs, vendors and grid applications.

CGMES

Common Grid Model Exchange Standard

Equipment

Transformers, lines, generators, switches and other grid equipment.

Steady State Hypothesis

Specific data subset containing operational input parameters needed to perform power flow and steady-state analysis on an electrical grid.

Topology

Connectivity nodes, terminals and network topology.

State Variables

Voltage, power flow and operational state information.
